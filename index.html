Политика конфиденциальности игры «Только толкай»

Разработчик: Emberlane. Дата: 17 ноября 2026 года.

1. Игра не требует регистрации. Прогресс, настройки звука, языка и цвета героя хранятся только на устройстве и удаляются вместе с приложением.

2. В игре показывается реклама через Yandex Mobile Ads SDK (ООО «Яндекс»). Игра предназначена для всех возрастов, поэтому реклама показывается без персонализации: SDK не подбирает объявления по интересам пользователя. Для показа и подсчёта рекламы SDK может получать сведения об устройстве и сети и приблизительное местоположение по IP-адресу. Обработка этих данных регулируется политикой конфиденциальности Яндекса: https://yandex.ru/legal/confidential/

3. Для улучшения игры используется сервис аналитики AppMetrica (ООО «Яндекс»). Он получает обезличенные сведения: модель и версию системы устройства, язык, страну по IP-адресу, время и длительность игровых сессий, пройденные уровни, использование подсказок, просмотры рекламы и покупки в игре, а также отчёты о сбоях. Рекламный идентификатор и геолокация устройства не собираются. Данные используются только в обобщённом виде, чтобы понимать, какие уровни слишком сложные и как улучшить игру. Условия AppMetrica: https://yandex.ru/legal/metrica_termsofuse/ru/

4. Покупка «Без рекламы» проводится через RuStore Pay SDK (ООО «ВК»). Платёжные данные обрабатывает RuStore, разработчик их не получает. Правила RuStore: https://www.rustore.ru/help/legal

5. Разработчик не получает имени, телефона, почты и других данных, по которым можно узнать пользователя, и не продаёт данные третьим лицам.

6. Игра не запрашивает доступ к контактам, камере, микрофону, точной геолокации и файлам устройства.

7. Вопросы о политике конфиденциальности: emberlane.gamedev@gmail.com
